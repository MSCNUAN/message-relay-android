## Release Notes

```markdown
## 消息接力 v0.1.3 Beta

仓库地址：https://github.com/MSCNUAN/message-relay-android

### 新增

- Bark 设备支持绑定 App。绑定后，该 App 的 Bark 推送只发往已绑定的有效 Bark。
- 软件选择页每个 App 增加明确的“设置”入口。
- SIM 卡管理页显示电话权限、联系人权限、通话记录权限、Telephony 支持状态和 SIM 读取原因。

### 优化

- 首页快捷卡片改为更稳的单列布局，改善大字体和窄屏下的文字裁切。
- 覆盖更新时，如果已有渠道或规则，会自动恢复为已完成配置。
- 推送渠道页在加密渠道读取失败时给出明确提示。
- Bark 绑定随渠道备份和恢复。

### 修复

- 修复“仅息屏时推送”入口难找的问题。
- 修复覆盖更新后可能重新进入首次配置的问题。
- 修复 SecureStore 解密失败可能导致渠道页崩溃的问题。
- 修复软件选择推荐区可能误显示系统组件的问题。
- 修复发布文档和用户可见文案中的中文乱码。

### 安装说明

1. 下载 APK。
2. 在 Android 设备上允许安装来自浏览器或文件管理器的应用。
3. 安装后按首页提示配置通知访问、推送渠道和软件选择。

### 权限说明

本应用可能使用通知访问、通知权限、设备应用列表、电话状态、通话记录、联系人和短信接收权限。所有筛选和模板处理均在本机完成。

### 已知限制

- 电话、双卡、AOD/Doze 和不同品牌后台保活仍需要更多真机验证。
- 来电号码、联系人、归属地和运营商信息受系统权限、Android 版本和厂商限制影响。
- Bark、飞书、钉钉实际送达取决于网络、机器人配置和服务端状态。

### 校验

- APK SHA-256：发布前填写
```
